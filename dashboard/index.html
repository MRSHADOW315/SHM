إعداد الاتصال والإطار

حدد عنوان خدمة وسيطة تثق بها فقط.

GitHub Pages لا يغيّر اتصال الجهاز أو يشغّل بروكسي بنفسه. الوكيل الذي تختاره قد يرى المواقع والبيانات التي تمر عبره؛ لا تستخدم خدمة مجهولة أو لإخفاء مخالفات.

هذا الإعداد يفتح المواقع داخل إطار الصفحة فقط؛ لا يغير الشبكة ولا يتجاوز قيود المواقع أو الحجب. يلزم أن تكون البوابة متوافقة مع سياسة المتصفح.
